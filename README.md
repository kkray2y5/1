# Начало

Минимальный адаптивный сайт на русском языке. Обычные HTML и CSS: пакеты, сборка, внешние сервисы и секреты не требуются.

## Запуск

Нужен Python 3. В облачной среде он уже установлен.

```bash
cd /workspace/1
python3 -m http.server 8000 --bind 127.0.0.1 --directory public
```

Сервер предназначен для локальной разработки. Остановить его можно клавишами Ctrl+C.

## Проверка

Из другого терминала:

```bash
curl --fail --silent http://127.0.0.1:8000/
curl --fail --silent http://127.0.0.1:8000/styles.css
```

Оба запроса должны завершиться успешно и вернуть HTML и CSS соответственно. Это проверка доступности файлов; автоматических браузерных тестов пока нет.

## Изменение сайта

- `public/index.html` — содержимое и структура страницы.
- `public/styles.css` — оформление и адаптация к размерам экрана.

Сервер раздаёт только каталог `public`, а не служебные файлы репозитория. После редактирования обновите страницу: отдельная сборка не нужна.
